# MaGiBu

**MaGiBu** (Methylation-based Guided Builder) is a modular R framework for building methylation-based classification models. It is platform-agnostic, supporting both Illumina methylation arrays (450K, EPIC, EPICv2) and Oxford Nanopore sequencing data.

### Step 10-B: Process New Sample Nanopore BAM Files

Nanopore BAM files (aligned to hg38, with MM/ML methylation tags, sorted and indexed) can be converted
into the TSV files used by `project_new_samples` in two equivalent ways.

**Option 1 - magibu-meth (faster).** `magibu-meth` (C, htslib; binary in `App/app/bin/`) reads the
methylation tags directly from the BAM and writes the same entropy file as modkit + ModkitResorter.sh
(identical row by row on a 30x whole-genome BAM, in 6.5 minutes with 16 threads):

```
REF=hg38.fasta # your fasta reference. It must match the one used for the BAM alignment.
THN=16
magibu-meth --ref ${REF} -t ${THN} -o sample_sorted.entropy.file.tsv dorado.output.bam
mv sample_sorted.entropy.file.tsv /path/to/tsv/new_samples
```

Output: one row per CpG, tab separated, no header.

| Column | Content |
|:---:|---|
| 1 | chromosome |
| 2 | position (0-based C of the CpG, both strands combined) |
| 3 | entropy of the CpG (window of 3 consecutive CpGs) |
| 4 | reads carrying the full 3-CpG pattern |
| 5 | **beta** |
| 6 | coverage (confident calls) |

A call is methylated if p5mC > 0.85 and unmethylated if p5mC + p5hmC < 0.3; the others are discarded
(same rules as ParseModkit.pl of PoreMeth2).

**5mC and 5hmC.** With a BAM basecalled with a dorado `5mC_5hmC` model, magibu-meth can keep the two
modifications apart or add them up:

| Option | Column 5 (beta) | Extra columns |
|---|---|---|
| none (default) | 5mC (original rule) | none |
| `--sum-5hmc` | 5mC + 5hmC (methylated if p5mC + p5hmC > 0.85) | none |
| `--split-5hmc` | as above, unchanged | 7 `beta_5mC`, 8 `beta_5hmC`, 9 `n` |

With `--split-5hmc` each call is 5mC (p5mC > 0.85), 5hmC (p5hmC > 0.85), unmodified C
(p5mC + p5hmC < 0.3) or ambiguous (discarded), and `beta_5mC = n5mC / n`, `beta_5hmC = n5hmC / n`,
`n = n5mC + n5hmC + nC`. Columns 1-6 do not change, so the file stays compatible with every script that
reads column 5. `beta_5hmC` is `NA` when the BAM has no 5hmC calls (5mC-only basecalling model).
`--split-5hmc` can be combined with `--sum-5hmc`.

```
# entropy + 5mC and 5hmC kept apart, in one run
magibu-meth --ref ${REF} -t ${THN} --split-5hmc -o sample_sorted.entropy.file.tsv dorado.output.bam
```

Then choose which beta goes into the classification in Step 1-B (`nanopore.settings`):

```r
# 5mC and 5hmC separated: beta_5mC (column 7, needs --split-5hmc)
nanopore.settings = c(chr = "V1", pos = "V2", beta = "V7")
# 5mC only (original rule) or 5mC + 5hmC summed (file made with --sum-5hmc): column 5
nanopore.settings = c(chr = "V1", pos = "V2", beta = "V5")
```

Other options:

| Option | Meaning |
|---|---|
| `-r regions.bed` | read only these regions (much faster); without it, the whole genome |
| `--ref hg38.fasta` | CpG sites from the reference (needs the `.fai`). Without it they are taken from the reads |
| `--no-entropy` | beta only: no 3-CpG window, columns 3-4 written as `NA` |
| `--min-cov N` | confident calls needed to write a CpG (default 3) |
| `--full-precision` | beta and entropy with full precision instead of 4 decimals |
| `-t N` | threads |

**Option 2 - modkit + ModkitResorter.sh.** Run modkit with the following command:

```
REF=hg38.fasta # your fasta reference. It must match the one used for the BAM alignment.
THN=10
modkit extract full --mapped-only --threads ${THN} --cpg --reference ${REF} dorado.output.bam modkit.output.tsv
```

Then run the PoreMeth2 script ModkitResorter.sh.
You can retrieve ModkitResorter.sh and ParseModkit.pl (required) from [PoreMeth2](https://github.com/Lab-CoMBINE/PoreMeth2/tree/master/AdditionalScripts).

```
sh ModkitResorter.sh modkit.output.tsv
mv *sorted.entropy* /path/to/tsv/new_samples
```

It generates the TSV files used by the `project_new_samples` function. This option gives column 5 only
(5mC): to keep 5mC and 5hmC apart use Option 1 with `--split-5hmc`.

> ⚠️ **Important**: Again, ensure the output directory contains **only** methylation TSV files.

### Step 3: Visualize Results

Create a sample ID vector from your processed files:

```r
my_samples <- gsub("\\.tsv$", "", list.files("path/to/tsv/new_samples"))
```

> **Note**: The order of sample names in this vector determines the order of results.

#### Generate UMAP Plot
```r
plot_umap_zoom_combined(
 metadata.in = projected$metadata,
 output.path = "path/to/plots",

)
```

#### Examine Classification Distances
```r
get_top_3_distances(
 projected$metadata,
 sample_ids = my_samples
)
```

This function returns the three nearest reference classes for each sample, along with their distances, useful for assessing classification confidence.
